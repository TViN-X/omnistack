# OmniStack

**OmniStack** — это автоматизированный стек развертывания веб-панели **3X-UI** и сетевой инфраструктуры. Скрипт объединяет веб-сервер Nginx, автоматический выпуск и продление SSL-сертификатов, оптимизацию сетевого стека Linux, генерацию мультиклиентских подписок и систему автоматического обслуживания сервера.

---

## ⚡ Основные возможности

- **Архитектура единого домена (Single-Domain):** веб-панель управления, веб-портал подписок и сетевые шлюзы мультиплексируются через веб-сервер Nginx на стандартных веб-портах (`80` и `443`).
- **Автоматизация SSL:** автоматический выпуск и регулярное продление доверенных SSL-сертификатов Let's Encrypt через механизм ACME webroot без прерывания работы сервисов.
- **Поддержка сетевых протоколов:** автоматическая конфигурация входящих потоков VLESS (Reality, XHTTP, WebSocket), Hysteria 2, WireGuard и AmneziaWG (1.0 / 3.1).
- **Оптимизация сетевого стека Linux:** автоматическое включение алгоритма контроля перегрузок TCP BBR и оптимизация системных буферов передачи данных.
- **Автономный генератор маскировочных веб-сайтов:** встроенный генератор 15 реалистичных русскоязычных тем лендингов («Сайт в разработке», «Технические работы», «Скоро открытие») на чистом HTML5/CSS без внешних CDN-зависимостей.
- **Еженедельное резервное копирование в Telegram:** автоматический экспорт базы данных и отправка сводной статистики сервера в Telegram-бота по воскресеньям.
- **Автообновление баз маршрутизации:** еженедельная автоматическая загрузка свежих баз GeoIP и Geosite по расписанию через Cron.
- **Мультиклиентские подписки:** единый веб-портал для пользователей и поддержка автоматической генерации ссылок маршрутизации для приложений Happ, Incy, Clash/Mihomo и Sing-box.
- **Встроенная диагностика сети:** экспресс-аудит доступности внешних сетевых сервисов и замер сетевой задержки (RTT/ping).

---

## 📋 Требования

- **Операционная система:** Ubuntu 22.04 / 24.04 LTS или Debian 11 / 12
- Чистый сервер с правами суперпользователя `root`
- Доменное имя с настроенной A/AAAA записью на IPv4-адрес сервера
- Открытые входящие порты `80` и `443` (TCP/UDP)

## 🚀 Установка

Подключитесь к серверу по SSH под пользователем `root` и выполните команду:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/TViN-X/omnistack/master/omnistack.sh)
```

или через `wget`:

```bash
bash <(wget -qO- https://raw.githubusercontent.com/TViN-X/omnistack/master/omnistack.sh)
```

### Режимы развертывания

Во время интерактивной установки скрипт предложит выбрать режим работы сервера:

1. **Exit Node (Внешний сервер)** — прямой выход в интернет с изоляцией локальных сетей в Blackhole.
2. **Cascade Ingress (Сервер с каскадом)** — режим со сплит-маршрутизацией: локальные сервисы обрабатываются напрямую, выбранный внешний трафик передается в вышестоящий туннель.
3. **Standalone (Автономный сервер)** — независимый узел внутри сети без вышестоящих туннелей.

---

### Неинтерактивная установка (флаги CLI)

Вы можете запустить установку без диалоговых окон, передав параметры:

```bash
# Автономный сервер (Standalone)
bash <(curl -fsSL https://raw.githubusercontent.com/TViN-X/omnistack/master/omnistack.sh) -role standalone -domain your-domain.com

# Внешний сервер (Exit Node)
bash <(curl -fsSL https://raw.githubusercontent.com/TViN-X/omnistack/master/omnistack.sh) -role exit -domain your-domain.com

# Каскадный сервер (Cascade Ingress)
bash <(curl -fsSL https://raw.githubusercontent.com/TViN-X/omnistack/master/omnistack.sh) -role cascade -domain your-domain.com -cascade_url "vless://..."
```

## 🛠️ Управление сервером

После установки в системе регистрируется глобальная команда `omnistack`:

```bash
# Вызов интерактивного главного меню
omnistack

# Смена темы сайта-заглушки (выбор 1-15 или случайная)
omnistack -fake
omnistack -fake 3
omnistack -random-fake

# Проверка сетевой доступности внешних сервисов
omnistack -check

# Замер задержки (RTT/ping) и автоподбор доменов для Reality
omnistack -scan

# Ручной запуск резервного копирования в Telegram
omnistack -backup

# Обновление баз маршрутизации GeoIP и Geosite
omnistack -update-geodata

# Установка базового системного софта (утилиты, безопасность)
omnistack -base-soft

# Полное удаление OmniStack и очистка системы
omnistack -uninstall y
```

### Управление службой 3X-UI

Для управления службой панели (сброс пароля, статус, перезапуск службы):
```bash
x-ui
```
